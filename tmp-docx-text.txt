Prompt 1 — Fix all routing/auth redirect bugs
In Infusion Studio, multiple pages redirect to /login when a logged-in user clicks on items they created (ingredients, blends, low-stock alerts on dashboard). Audit every client-side fetch in src/app/(dashboard) and every API route in src/app/api. Ensure: (1) every API route calls getSessionUser() at the top and returns { error: 'Unauthorized' } with status 401 — never a redirect; (2) client pages handle a 401 response by calling router.push('/login') themselves rather than relying on middleware; (3) AppLink components always have a defined href before rendering. Fix the blend creator save button which incorrectly redirects to the landing page on a failed save — it should show an error toast instead.
Prompt 2 — Dashboard improvements
In src/app/(dashboard)/dashboard/page.tsx and src/app/api/dashboard/route.ts: (1) Make the 4 stat cards (Ingredients, Blends, Recipes, Favorites) clickable — wrap each in AppLink to /ingredients, /blends, /recipes, /favorites; (2) Fix inventory value overflow when price is very large — use Intl.NumberFormat with notation:'compact' for values over 999999; (3) Wrap the CategoryChart in a Card component matching the Inventory Value card; (4) Add tiered low-stock colouring: quantity <= 10 = red (border-red-300 bg-red-50), quantity 11-18 = amber (current), 19-50 = unchanged; (5) In sidebar.tsx reorder mainNavItems so Timer appears immediately after Blend Creator; (6) In the API route replace the hardcoded LOW_STOCK_THRESHOLD=50 with ingredient.lowStockThreshold ?? 50 (add that field to the Prisma schema first).
Prompt 3 — Ingredient page fixes
In src/components/ingredients/ingredient-form.tsx and related pages: (1) Group the Sort By and Sort Order filter controls in search-filters.tsx under a shared 'Sort' label with a flex gap-2 wrapper; (2) Add a datalist to the origin input with common tea origins (China, Japan, India, Sri Lanka, Taiwan, Kenya, Nepal); (3) Replace the quantity stepper with NumberInput (step=1, default=0) or fix StepperInput to allow step=1; (4) Add isDirty from react-hook-form formState to disable the Save button when no changes have been made; (5) Show a ConfirmModal when Cancel is clicked and isDirty is true — 'Discard changes?'; (6) Add a quick stock adjustment UI to the ingredient detail page: two buttons (Use some / Restock) that open a small modal with a NumberInput and call POST /api/ingredients/[id]/stock with { delta: number }. Create that new API route.
Prompt 4 — Blend Creator & detail fixes
In src/components/blends/blend-creator.tsx and src/app/(dashboard)/blends/[id]/page.tsx: (1) Move the blend name Input and description Textarea above the two-column palette/canvas grid so they are full-width at the top; (2) Wire the existing blendSchema .max(100) and .max(500) Zod limits to the form — show character counters and inline error messages; (3) Replace the two NumberInput components for brewTemp and brewTime with StepperInput (step=5 for temp 40-100°C, step=30 for time 30-3600s); (4) Add unit toggles: °C/°F for temp, sec/min for time — store in °C and seconds internally; (5) Add a Back AppLink to /blends alongside the Reset button; (6) On the blend detail page move the Brew/Start Timer button to below the ingredients Card; (7) In the Save as Recipe modal add validation using recipeSchema — show error if name > 100 chars; (8) On edit page unmount, call useBlendStore.getState().reset() only if save did not complete, to prevent stale blend data persisting in the creator.
Prompt 5 — Brew timer improvements
In src/app/(dashboard)/timer/page.tsx and src/components/timer/brew-timer.tsx: (1) Reorder the timer page so Custom Duration appears above Quick Presets; (2) Replace the single minutes NumberInput with three side-by-side NumberInput fields (HH / MM / SS) that compute seconds = h*3600 + m*60 + s on change; (3) When the timer completes (isComplete), call Haptics.vibrate({ duration: 1500 }) from @capacitor/haptics (install it) and play a soft chime using Web Audio API as a PWA fallback; (4) Install @capacitor/local-notifications and schedule a local notification when the timer starts: fire at Date.now() + seconds*1000 with title 'Brew Complete' and body = blendName. Cancel the notification on reset. This ensures the alert works even when the screen is locked.
